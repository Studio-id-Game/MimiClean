# MimiCleanUnity
- [Repository](https://github.com/Studio-id-Game/MimiClean)

クリーンアーキテクチャ風の仕組みを提供する、シンプルな C# (.NET Standerd 2.0) 向けライブラリのUnityパッケージです。

Developed by Studio-id-Games, hirohiroj3cub.

# Adding Dependencies

- MimiCleanUnityを利用するためには、以下の参照の追加が必要です。

## UniTask

- [Repository](https://github.com/Cysharp/UniTask/)
- For example, via Unity’s Package Manager

## Microsoft.Extensions.DependencyInjection

- [Repository](https://github.com/dotnet/runtime/)
- For example, via NuGetForUnity
- [NuGetForUnity](https://github.com/GlitchEnzo/NuGetForUnity/)
